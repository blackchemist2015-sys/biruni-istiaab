# الملاحق

## ملحق ١: مسرد المصطلحات

| المصطلح | معناه | المقابل الحديث |
|:--------|:------------------|:---------|
| الأم | الجسم المجوّف الذي تُوضع فيه الصفائح | mater |
| الحجرة | حافة الأم المقسومة بالأجزاء | limb |
| الكرسي | الجزء البارز الذي فيه العروة والحلقة | throne |
| العروة، الحلقة | ما تُعلّق به الآلة | shackle, ring |
| الصفيحة | لوح فيه المقنطرات لعرض معين | plate |
| العنكبوت | الشبكة المخرّقة التي فيها المنطقة والكواكب | rete |
| الشظية | رأس الكوكب في العنكبوت | star pointer |
| الفلس | القرص الصغير في وسط العنكبوت | central boss |
| العضادة | المسطرة الدائرة على الظهر، فيها اللبنتان | alidade |
| العضادة المحرّفة | التي حرفها الدالّ مارٌّ بالمركز | bevelled alidade |
| اللبنة، الهدفة | صفيحتا الرصد المثقوبتان على العضادة | sighting vanes |
| القطب، الفرس | المحور والإسفين الماسك له | pin, wedge ("horse") |
| المدار | دائرة ميل ثابت يدور عليها الكوكب | day-circle |
| مدار الحمل | معدل النهار مسطّحًا | equator |
| المقنطرة | دائرة ارتفاع ثابت | almucantar |
| مقنطرة الانحطاط | دائرة ارتفاع سالب | depression circle |
| دائرة السمت | دائرة عظيمة تمر بسمت الرأس | azimuth circle |
| أول السموت | دائرة السمت القائمة على نصف النهار | prime vertical |
| سمت الرأس | النقطة التي فوق الرأس | zenith |
| المطالع | المطلع المستقيم | right ascension |
| درجة الممر | درجة البروج التي تتوسط السماء مع الكوكب | culminating degree |
| الميل الكلي | ميل فلك البروج على معدل النهار | obliquity of the ecliptic |
| التسطيح | نقل الكرة إلى السطح | projection |
| قطب التسطيح | النقطة التي منها يكون الإسقاط | centre of projection |
| الدستور | لوح القسمة المرجعي | template |
| الساعات الزمانية | جزء من اثني عشر من النهار أو الليل | seasonal (unequal) hours |
| الساعات المستوية | خمسة عشر جزءًا من دوران الفلك | equal hours |
| الظل المستوي، المعكوس | ظل المقياس القائم، والموازي للأفق | cotangent, tangent shadow |
| القطع الناقص، المكافئ، الزائد | مقاطع المخروط | ellipse, parabola, hyperbola |
| القطر المجانب، الضلع المائل | المحور القاطع للقطع | transverse diameter |
| الضلع القائم | الوتر البؤري العمودي | latus rectum |
| الخطان اللذان لا يلقيان القطع | الخطان المقاربان | asymptotes |
| البركار التام | بركار المخروط لأبي سهل الكوهي | conic compass |
| النرماذجة | المفصل الدوّار | hinge |
| حُقّ القمر | آلة مسنّنة تُري أوجه القمر | lunar gear box |
| المُري | المؤشّر | pointer |
